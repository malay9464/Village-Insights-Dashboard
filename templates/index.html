METHODOLOGY

Know what the data says.

Transparency about the source, processing and limits of this dashboard.

ⓘ
01

Source

The dashboard reads the supplied Excel workbook, sabarkantha_synthetic_visualization_2024_3500_records.xlsx, from the project folder.

02

Data status

The workbook is synthetic/simulated data for visualization practice. It is not an official census, government survey or verified village register.

03

Aggregation

Repeated rows are deduplicated by year and village for the dashboard summaries to reduce accidental double-counting of village totals.

04

Filter scope

Year, taluka and village filters apply to all dashboard metrics. Crop selection applies to agriculture and employment summaries, and to record-level explorer results. It does not change population, education or infrastructure summaries.

05

Interpretation

Rates are descriptive averages. Service flags show reported availability, not quality, capacity or accessibility. Do not use these figures for policy decisions.

ABOUT THIS PROJECT

Village Insights

A practical demonstration of interactive data analysis for Sabarkantha district.

✳
PROJECT

Purpose

This student demonstration brings demographic, education, infrastructure and agriculture fields together in a filterable dashboard built with Flask, pandas, SQLite and Chart.js.

DATA

Use with care

The supplied 3,500-row workbook is synthetic. It is useful for learning about data summaries and visualization, but does not describe actual villages or support official decisions.
